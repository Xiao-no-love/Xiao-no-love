写代码的初衷很简单——**看不惯手动重复**。
于是慢慢从"写点脚本偷懒"，走到了"让 AI 替我操作电脑"。

- 🔭 现在在做：[**DeepHelp**](https://github.com/Xiao-no-love/DeepHelp) —— 一个能真正读写文件、执行命令的本地 AI 助手
- 🌱 在学：AI Agent · 浏览器自动化 · LLM 工程化
- 🎯 原则：先让它跑起来，再让它跑得漂亮
